# 📊 Power BI Dashboard

The Power BI dashboard is the **reporting and visualization layer** of
the Automobile Showroom Sales Analytics project.

The main purpose of this dashboard is to turn the processed Gold/Synapse
data into a simple and interactive report that helps understand showroom
sales performance.

## 🎯 Dashboard Objective

The dashboard provides a quick view of:

-   💰 Sales revenue
-   📈 Profit performance
-   🚗 Vehicles sold
-   📊 Profit percentage
-   🚘 Model performance
-   🏷️ Brand performance
-   👨‍💼 Salesperson performance
-   🏆 Top-selling models
-   🔄 Lead conversion
-   🏢 Showroom performance

The report is designed so users can select a **showroom** and a **date
period** and analyze the corresponding results.

## 🖥️ Dashboard Overview

The dashboard contains the following main sections.

### 💳 KPI Cards

The top section shows important business KPIs:

-   **Total Sales Revenue**
-   **Total Profit**
-   **Total Vehicles Sold**
-   **Average Profit %**

These cards provide a quick snapshot of the selected showroom and time
period.

### 🚘 Revenue by Model

Shows the revenue generated by different vehicle models.

This helps identify which models are contributing the most to sales
revenue.

### 🏷️ Revenue by Brand

Shows the contribution of vehicle brands to total revenue.

This makes it easier to understand brand-level sales performance.

### 👨‍💼 Revenue by Salesperson

Shows revenue generated by individual salespersons.

It can be used to compare salesperson performance and identify top
performers.

### 🏆 Top 5 Models Sold

Shows the models with the highest number of vehicles sold during the
selected period.

### 🔄 Lead Conversion Funnel

Shows the progression of showroom leads and helps understand how many
leads are converted into actual sales.

This gives a simple view of the effectiveness of the sales process.

### 🏢 Revenue by All Showrooms

Shows revenue performance across different showrooms.

This helps compare showroom-level performance.

## 🎛️ Interactive Filters

The dashboard includes filters such as:

### Showroom

Users can select a specific showroom to view its performance.

### Date

Users can select the required reporting period, such as the latest
month.

The visuals and KPI cards respond to these selections.

## 🔗 Data Source

Power BI consumes the processed analytical data from the project's
serving layer.

The overall data flow is:

``` text
🗃️ MSSQL + PostgreSQL
        ↓
⚙️ Azure Data Factory
        ↓
🗄️ ADLS Gen2 — Bronze
        ↓
🧹 Databricks — Silver
        ↓
💎 Databricks — Gold
        ↓
🏢 Azure Synapse Analytics
        ↓
📊 Power BI
```

Power BI is therefore not responsible for the main data transformation.
The heavy data engineering work is completed before the data reaches the
reporting layer.

## 🔄 Monthly Reporting

The dashboard is designed as part of the project's monthly automation
process.

``` text
📅 1st Day of Month
        ↓
⚙️ ADF Pipeline
        ↓
📥 Data Extraction
        ↓
🥉 Bronze
        ↓
🥈 Silver
        ↓
🥇 Gold
        ↓
🏢 Synapse
        ↓
🔄 Power BI Dataset Refresh
        ↓
📊 Updated Dashboard
```

The final objective is to have the latest showroom sales information
available in Power BI every month with minimal manual intervention.

## 📌 Key Business Questions

The dashboard can help answer questions such as:

-   💰 How much revenue was generated?
-   📈 How much profit was made?
-   🚗 How many vehicles were sold?
-   🚘 Which models are performing best?
-   🏷️ Which brand generates the most revenue?
-   👨‍💼 Which salesperson generates the highest revenue?
-   🔄 How many leads are being converted?
-   🏢 Which showroom is performing best?
-   📊 How does performance change over the selected period?

## 🛠️ Tools Used

-   **Power BI** --- Dashboard and visualization
-   **Azure Synapse Analytics** --- Analytical/serving layer
-   **Azure Databricks** --- Data transformation
-   **Azure Data Lake Storage Gen2** --- Data lake
-   **Azure Data Factory** --- Data ingestion and orchestration
-   **Microsoft SQL Server** --- Source database
-   **PostgreSQL** --- Source database

## 🚀 Final Outcome

The Power BI dashboard provides a business-friendly view of the complete
showroom sales data pipeline.

Instead of manually checking different source systems, users can use one
interactive dashboard to understand **sales, profit, vehicle
performance, salesperson performance, lead conversion, and showroom
performance**.

> **The goal is to make the monthly showroom sales report automated from
> data extraction all the way to the final Power BI dashboard.**
